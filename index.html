01 — OUR APPROACH

Good data should lead to better questions.

LumenPath Learning is a fictional education-technology company exploring how machine learning can help schools notice patterns that are easy to miss in a busy classroom.

We bring together signals like attendance, practice time, prior performance, and assignment results. Our models demonstrate possible patterns; educators provide the context, conversation, and care that data cannot.

✦
OUR MISSION

Make learning support more timely.

Give educators understandable insights that can guide early check-ins and practical support plans.

↗
OUR VISION

A path forward for every learner.

Help build education environments where patterns open conversations instead of defining a student's potential.

◎
OUR GOALS

Turn patterns into next steps.

Forecast performance, identify possible support needs, compare learner profiles, and explain each model's role.

!
THE CHALLENGE WE ADDRESS

Learning difficulties can appear as small signals before a major setback.

Educators may have many records but limited time to connect them. A well-chosen model can help prioritize a review—without replacing teacher judgement or a student's own voice.

02 — THE ML TOOLKIT

Six models. Six different questions.

Machine learning is not one universal solution. Each algorithm offers a different lens on the learning journey.

MODEL 01

Linear Regression

“What score might a learner achieve?”

Estimates a numeric outcome by learning a best-fit relationship between input features and past scores.

TYPEPrediction · numeric
USESAttendance, practice, prior score, assignments
EXAMPLE OUTPUTPredicted final score: 78 / 100Example only; the live demo calculates a new estimate.
MODEL 02

Naive Bayes

“Could this learner need a check-in?”

Combines probabilities from several signals, assuming those signals are conditionally independent given the class.

TYPEClassification · probability
USESAttendance band, practice band, score bands
EXAMPLE OUTPUTSupport flag likelihood: 72%A probability estimate—not a diagnosis or certainty.
MODEL 03

K-Nearest Neighbors

“Who has a similar learning profile?”

Compares a learner's features with nearby examples and uses their labels or values to estimate a result.

TYPESimilarity-based prediction
USESNormalized attendance, practice, prior and assignment scores
EXAMPLE OUTPUTNearest 3: 2 need supportSimilar profiles can inform a review, not determine a student's future.
MODEL 04

Support Vector Machine

“Which side of the boundary is this profile on?”

Finds a decision boundary that separates classes while seeking a wide margin between groups.

TYPEClassification · margin-based
USESAttendance, practice time, prior score, assignments
EXAMPLE OUTPUTClass: Review recommendedThe boundary reflects patterns in this small synthetic sample.
MODEL 05

Decision Tree

“Which signals led to this flag?”

Uses a series of feature-based splits to reach a prediction through a path of understandable rules.

TYPERule-based classification
USESThresholds in attendance, prior score, practice and work
EXAMPLE OUTPUTDecision path: Attendance → ScoreShows the path the model followed through its learned tree.
MODEL 06

Artificial Neural Network

“Can several signals combine into a useful pattern?”

Learns weighted combinations of inputs through connected processing units; it can capture non-linear relationships.

TYPENon-linear classification
USESMultiple scaled indicators and a labelled training set
EXAMPLE OUTPUTSupport probability: 0.81A model score should be validated before any real use.
ⓘ

Why use different models? Regression predicts a number; classification groups cases; KNN compares neighbors; and a tree provides a readable decision path. SVM and neural networks offer other ways to separate patterns. Model choice should match the question, the data, and the cost of being wrong.

05 — RESPONSIBLE USE

Insight is a starting point.
People make the difference.

Education data is sensitive. A real deployment would need informed governance, strong access controls, transparent communication, quality checks, and ongoing evaluation across student groups.

01

Check the data. Small or biased samples can create misleading patterns.

02

Explain the result. A score or flag should come with context and limitations.

03

Keep people involved. Teachers and students should help decide what support is appropriate.
